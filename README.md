rooted-graphene-ota
===

Personal OTA builds of [rooted-graphene](https://github.com/schnatterer/rooted-graphene)

This is a wrapper around upstream: a single workflow (vendored from
[rooted-graphene/ota's `release-single` workflow](https://github.com/rooted-graphene/ota/blob/main/.github/workflows/release-single.yaml))
which runs the [upstream build script](https://github.com/schnatterer/rooted-graphene) with this repo's signing keys.
